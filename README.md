# Ares-Arena
# 概要
- ジャンル：ターン制パズルローグライク
- 対応言語：日本語、英語
- ハード：Windows, WebGL

アリーナにて聖戦が開かれようとしている！
戦いの神を信仰するセイントとなり、聖戦を勝ち進みましょう。
宝石やスキルを駆使して敵の様々な能力を掻い潜り、勝利と栄光を掴み取れ！

# 特徴
- 豊富な種類のキャラクターや装備による戦術の多様性、多彩な能力を持つ敵とのユニークな戦闘
- キーボード操作不要、マウスのみを使用
- QTEや制限時間無し、自分のペースでプレイ可能

# 必要条件
- 開発環境 Unity 6000.3 以上
- 動作環境 Windows10/11, 4GB RAM, 64bitプロセッサとオペレーティングシステムが必要
